# Пары 3D — расписание КНИТУ

Трёхмерная версия сайта [«Пары»](https://samkrusa.github.io/pary/) — тот же функционал
(группы, недели, карточки пар, преподаватели, аудитории, работа офлайн),
но с полностью переработанным дизайном: стеклянные панели, объёмные карточки,
живой WebGL-фон с кристаллом и частицами, анимации входа.

**Живая версия:** https://samkrusa.github.io/pary-3d/

## Чем отличается от оригинала

- новый визуальный язык: тёмная тема, стекло, светящиеся акценты, типографика Manrope + Unbounded;
- объёмный интерфейс: наклон карточек за курсором, параллакс, подсветка под курсором;
- фоновая 3D-сцена на Three.js (собранная локально, без CDN) с кристаллом, орбитами,
  частицами и сеткой; отключается при `prefers-reduced-motion`;
- карточки занятий, сетка недели, лист выбора группы и модалка пары перерисованы с нуля;
- остальное поведение сохранено: `#g=slug` в адресе, сохранение группы в
  `localStorage` и cookie, офлайн-кэш, обновление «сейчас» раз в минуту.

## Данные и источник

Данные расписания берутся из того же проекта: [samkrusa/pary](https://github.com/samkrusa/pary),
первоисточник — [kstu.ru](https://www.kstu.ru). Скрипт `tools/scrape.py` и
GitHub Actions workflow скопированы из исходного репозитория, поэтому данные
обновляются так же — ежедневно в 02:00 UTC.

Оформление — оригинальное; сайт «Пары» не изменялся.

## Локальный запуск

```bash
python -m http.server 8080
# открыть http://localhost:8080
```

## Структура

```
index.html          разметка
style.css           оформление и анимации
app.js              логика расписания + 3D-сцена
three.min.js        Three.js r149 (локальная копия)
sw.js               офлайн-кэш
data/               расписания групп и институтов

```
